Automated WhatsApp order notifications, AI sales assistant, and live in-chat ordering for WooCommerce with zero external API monthly fees. Integrates seamlessly with the companion Desktop Software, Chrome Extension, and Android App.

== Description ==

Busistree WhatsApp Order & AI Sales Bot connects your WooCommerce store directly to your business WhatsApp account via our native desktop application, Chrome Extension, and mobile app.

= Key Features =
* **Zero Cloud API Fees:** Operates directly through your WhatsApp account via headless multi-device protocols and companion tools.
* **AI-First Sales & Support Assistant:** Understands customer inquiries in English, Roman Urdu, and Urdu script with fuzzy search, typo tolerance, and strict zero-hallucination factual grounding.
* **In-Chat & Direct Checkout Ordering:** Customers can browse items, search products, view store insights (cheapest, top seller, on sale), and initiate orders directly inside WhatsApp.
* **Safe Order Confirmations (YES/NO):** Automatic order confirmation requests for pending/COD orders with 1-click confirmation or cancellation.
* **Test Console & Shadow Mode:** Built-in chat simulator to test the bot safely, plus 24-hour default Shadow Mode so new connections never message customers without manual approval.
* **Dual Event Triggers:** Automated messages on new orders and status changes (Pending, Processing, Completed, Cancelled, On-Hold, Refunded).
* **Pakistani Number Normalization:** Automatically converts formats like 0300-1234567 or 3001234567 into international WhatsApp format (+923001234567).
* **Custom Message Templates:** Full support for dynamic placeholders ({customer_name}, {order_number}, {items_list}, {total}, {currency}, {site_name}, etc.).
* **1-Click WhatsApp Chat:** Direct WhatsApp chat button inside WooCommerce Orders list and Order Details edit screen.
* **High-Speed REST API:** Cached and secure REST endpoints for product search, order lookup, and queue polling.

== Installation ==

1. Upload the `busistree-whatsapp-notifier` folder to your `/wp-content/plugins/` directory, or upload the zip file via **Plugins > Add New > Upload Plugin**.
2. Activate the plugin through the **Plugins** menu in WordPress.
3. Navigate to **Busistree WhatsApp** in the WordPress admin menu.
4. Download the **Busistree Desktop App** from the *Download Apps* tab or copy your **Store URL** and **API Key** into the companion app settings.
5. Scan your WhatsApp QR code to link your business phone. Automated and AI sales workflows will begin immediately.
